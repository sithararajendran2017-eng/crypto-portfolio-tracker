Platform Architecture & Overview

System objectives, analytical forecasting pipelines, and technical specifications.

Production Prototype v1.0
Implemented System Features
Active & Functional
  1. Cryptocurrency Portfolio Tracking: Multi-asset tracking (BTC, ETH, SOL, BNB, etc.), position valuations, asset allocation percentages, and gain/loss computations.
  2. Interactive Forecasting Studio: User-driven parameter configuration supporting >10 cryptocurrencies, API lookback ranges (1–3 years), CSV dataset upload, and configurable forecast horizons (1, 7, 14, 30 days).
  3. Functioning ARIMA Econometric Model: Stationarity verification via the Augmented Dickey-Fuller (ADF) test, order selection via AIC minimization, and rolling walk-forward evaluation.
  4. Functioning LSTM Deep Neural Network: Strict training-only MinMaxScaler scaling, sliding sequence preparation (30-day lookback), Dropout regularization, EarlyStopping, and multi-step recursive forecasting.
  5. Scientific Performance Benchmarking: Comparative evaluation on identical 30-day chronological test partitions using standardized MAE, RMSE, and MAPE metrics.

Anti-Leakage Protocol

Chronological partitioning ensures that neither ARIMA differencing nor LSTM sequence scaling incorporates future test values. Both models evaluate on identical date windows, guaranteeing a scientifically sound comparison.
